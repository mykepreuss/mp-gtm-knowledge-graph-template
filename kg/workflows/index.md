# Workflows

Select the interface matching the requested output. Small edits and discussion need no formal workflow. Read relevant actual sources and existing handoffs before starting new work.

- [[kg/workflows/landing-page-hero]]: hero, problem, wedge, evidence and CTA for a concrete offer.
- [[kg/workflows/landing-page-section]]: a bounded website section with fit and proof.
- [[kg/workflows/category-pov-doc]]: source-supported market narrative and tradeoffs.
- [[kg/workflows/inbound-outline]]: outline with argument, mechanism and proof opportunities.

Use [[kg/templates/output-artifact]] for substantive outputs. For derivatives, discover prior versions and feedback first. Preserve ready-for-review, owner-approved, scheduled and published states separately.
