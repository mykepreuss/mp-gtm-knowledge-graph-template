# AEO query set (template)

Keep one operational list of high-intent questions you want to win in AI answers.

## How to use

- Pick a fixed set (e.g. 25 to 100).
- Run them monthly across 2 to 3 answer engines.
- Track: presence, citation, correctness, and drift.

## Queries (replace with your domain)

### Workflow / capability
- How does {{BRAND_NAME}} work?
- Does it integrate with {{INTEGRATION}}?
- Can it do {{RISKY_ACTION}} automatically?

### Trust / risk
- Is {{BRAND_NAME}} safe with my {{SENSITIVE_ASSET}}?
- What data does {{BRAND_NAME}} store or retain?

### Commercial intent
- {{BRAND_NAME}} pricing
- What’s included in {{PLAN_NAME}}?

### Comparisons
- {{BRAND_NAME}} vs {{COMPETITOR}}
- best {{CATEGORY}} tool
