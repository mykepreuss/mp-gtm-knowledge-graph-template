# JTBD and Struggling Moment Framework

> Keep initiatives grounded in the exact moment a user says: “I can’t keep doing this by hand.”

## Why this exists

- Jobs reveal causality (progress they hire you to make).
- Demand is born from struggle (without a struggling moment, there is no pull).
- Competition is the candidate set (manual, coworker, smaller tool, do nothing, named competitors).

## The four forces of progress

To switch, Push + Pull must exceed Habit + Anxiety.

| Force | The voice of the user | What you must show |
| :--- | :--- | :--- |
| Push | “I’m stuck / wasting time / taking risk.” | Name the struggle in plain language. |
| Pull | “This gets me to progress.” | Show the mechanism + proof artifacts. |
| Habit | “This is how we already do it.” | Acknowledge what’s comfortable today. |
| Anxiety | “What could go wrong?” | State boundaries, controls, and trust posture. |

## Struggling moment snapshot (template)

- Situation: When …
- Motivation: We want to …
- Outcome: So we can …

Optional:
- Candidate set: manual, coworker, smaller tool, do nothing, competitors, you
- Proof: link a call note, recording, doc, or shipped artifact
