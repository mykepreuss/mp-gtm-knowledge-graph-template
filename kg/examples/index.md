# Approved writing examples

Open this catalog when an audience/purpose match would help substantive writing. No organization examples are supplied with this template. Use the task's source and voice guidance until actual approval evidence exists.

Add a small number of references using [[kg/templates/example-writing]], only when recorded owner feedback establishes a useful example. Link canonical text and exact approved passage, audience, purpose, and current-use limits. Publication, scores, status, and agent preference are not approval. Reuse notes remain agent interpretation. Read the relevant example, not an entire corpus.
