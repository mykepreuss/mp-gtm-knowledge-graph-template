# Approved writing reference

Set a unique ID, `type: example`, appropriate status, and DERIVED_FROM links to canonical text and the approval record if it is a graph node. Add a when-to-open entry to the example catalog. Do not copy the source text or invent approval.

- Current-use limits: [unapproved neighboring material, superseded wording, changing facts].
- Reuse notes (agent interpretation): [useful pattern, not a new owner rule].
