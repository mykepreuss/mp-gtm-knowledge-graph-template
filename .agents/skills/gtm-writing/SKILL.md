# Write from the organization's graph

Resolve repository paths from the root containing this skill's `.agents/` folder. Use the current request and supplied wording to set purpose, audience and scope. Preserve targeted edits; do not require a workflow, examples, variants or a new record for a small edit.

Read `kg/canon/voice.md` for organization writing. Its placeholders are not an established voice: use supplied text and recorded direction, disclose a material missing reference, and do not claim a verified voice match.

For substantive work, read `AGENTS.md` and `kg/schema/knowledge-graph-schema.md`, then select a task through `context/context-pack.md` and `kg/workflows/index.md`. Read the relevant surface and, when helpful, the closest approved reference from `kg/examples/index.md`. Read the linked canonical passage and approval boundary. An example supplies a writing pattern, not facts or beliefs for unrelated copy. No matching example is a valid result.

For source-derived work, use the workflow's prior-output discovery. Read actual earlier copy and feedback before judging repetition or carrying a correction forward. Intentional returns may be useful without new findings. Ground a viewpoint in the owner's actual source-supported thought, not merely topic relevance or plausible advice. Do not manufacture metrics, anecdotes, quotes, tests, conviction, humor or uncertainty.

Review concrete meaning, reader value, truth/permission, and voice. Preserve the source's metric definition, unit, period and attribution. Separate ownership from contribution and synthetic from observed results. Distinguish material factual/meaning problems from optional editorial preferences; stop when the purpose and checks are satisfied. Numeric scores and simulated reviewers are optional only when requested.

For substantive work, use the existing artifact and `kg/templates/output-artifact.md` receipt. Preserve exact feedback at its scope; owner approval and publication are independent. Update the authoritative rule only when a durable correction is authorized. Do not create a review queue, copy a sample corpus, or add an upgrade merely because this skill ran. Use documented repository checks after edits. Drafting does not authorize publication or sending, and including private context does not clear it for disclosure.
